# Recursos

Logos, iconos y material gráfico de FreeTheNoize. Úsalos libremente para hablar del proyecto.

```
assets/
  logo/
    logo.svg              logo completo, vectorial (README, web)
    logo.png              logo completo, 2334×640 (redes, previsualización del repo)
  icons/
    favicon.svg           icono vectorial 32×32
    favicon.ico           favicon 16 + 32 px
    favicon-512.png       icono 512 px (avatar de la organización, PWA)
    apple-touch-icon.png  icono 180 px para iOS
```

Colores: fondo `#0a0a0a`, acento `#c6ff00`, texto `#f2f0ea`.

Los iconos que usa la app están en `freethenoize/ui/` (web) y `packaging/` (escritorio).
Para añadir material nuevo (capturas, banners…), crea una subcarpeta aquí y añádelo a esta lista.
